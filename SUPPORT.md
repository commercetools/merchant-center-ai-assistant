# Support

## Status: unsupported

Thanks for taking a look. This is commercetools Labs reference code: an AI assistant for the Merchant Center that we are glad to share, and glad if you find it useful.

It is shared as-is under the MIT license (see [LICENSE](./LICENSE)) and is not covered by commercetools support. That means we can't promise replies, fixes, a roadmap or a service level. Issues and pull requests are welcome, and we will look at them when we can.

## If you get stuck

- Start with the [documentation](./README.md) and [docs/troubleshooting.md](./docs/troubleshooting.md). Most setup problems are covered there.
- Fork it and make it yours. That is what the code is for.
- Ask in the commercetools community, or open a discussion here when Discussions are enabled. Other users may well have the answer.
- For the commercetools platform itself (the APIs, Connect, the Merchant Center), use your normal commercetools support channel.

## Security

Please keep secrets, credentials and project data out of issues and pull requests. If you think you have found a vulnerability, open an issue that names the affected area without exploit details and ask for a private channel. We can't promise a response time, but we do want to hear about it. How the connector handles secrets and data is described in [docs/security.md](./docs/security.md).
