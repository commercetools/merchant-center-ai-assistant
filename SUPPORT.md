# Support

## Status: unsupported

This repository is published by commercetools Labs as freely available reference code.
It is unsupported: there is no support commitment, no SLA and no roadmap commitment.

## What you can expect

- Nothing is guaranteed. The code is provided AS IS under the MIT license (see [LICENSE](./LICENSE)).
- Issues and pull requests are read on a best-effort basis and may be closed without an answer.
- Questions and ideas belong in the Discussions of this repository, when they are enabled. Nobody is obliged to answer.

## What to do instead

- Read the [documentation](./README.md), start with [docs/troubleshooting.md](./docs/troubleshooting.md).
- Fork the repository and adapt it to your needs.
- commercetools product support does not cover this repository, because it is unsupported.

## Security

Do not post secrets, credentials or project data in issues or pull requests. Do not publish exploit details of a suspected vulnerability in a public issue;
describe the affected area only and ask for a private channel. There is no response commitment. How the connector handles secrets and data is described in [docs/security.md](./docs/security.md).
